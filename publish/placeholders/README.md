# crates.io placeholders

These 0.0.1 crates reserve names for components that cannot be published yet:
their code depends on Rune or librio, or their short name is already taken on
crates.io. The real crates will be published as 0.1.0 or later; a published
version cannot be replaced, so these stay at 0.0.1.

See <https://github.com/lu-zero/rune-term> for the source.
