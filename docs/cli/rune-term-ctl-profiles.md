# rune-term-ctl profiles

## Usage

```
rune-term-ctl profiles [OPTIONS] <COMMAND>
```

## Commands

* [`list`](rune-term-ctl-profiles-list.md) — List configured profiles.
* [`show`](rune-term-ctl-profiles-show.md) — Show one profile by name.

## Options

* `-h, --help` — Print help (see a summary with '-h')

## Global options

* `--json` — Output machine-readable JSON.
* `--socket <PATH>` — Path to the control socket.
