# rune-term-ctl tabs

## Usage

```
rune-term-ctl tabs [OPTIONS] <COMMAND>
```

## Commands

* [`list`](rune-term-ctl-tabs-list.md) — List tabs/panes from the running instance.

## Options

* `-h, --help` — Print help (see a summary with '-h')

## Global options

* `--json` — Output machine-readable JSON.
* `--socket <PATH>` — Path to the control socket.
