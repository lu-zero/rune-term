# rune-term-ctl profiles show

Show one profile by name.

## Usage

```
rune-term-ctl profiles show [OPTIONS] <NAME>
```

## Arguments

* `<NAME>` — Profile name.

## Options

* `-h, --help` — Print help (see a summary with '-h')

## Global options

* `--json` — Output machine-readable JSON.
* `--socket <PATH>` — Path to the control socket.
