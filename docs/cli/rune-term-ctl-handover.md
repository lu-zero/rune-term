# rune-term-ctl handover

Flip the running instance's handover on: its exit hands its shells to keepers.

## Usage

```
rune-term-ctl handover [OPTIONS]
```

## Options

* `-h, --help` — Print help (see a summary with '-h')

## Global options

* `--json` — Output machine-readable JSON.
* `--socket <PATH>` — Path to the control socket.
